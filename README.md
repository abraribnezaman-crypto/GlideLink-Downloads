# GlideLink for Windows

Public Windows companion downloads for GlideLink, the Android remote control for your Windows PC.

## Downloads

The first Windows testing release is being prepared. Once published, installers and SHA-256 checksums will appear on the [Releases page](https://github.com/abraribnezaman-crypto/GlideLink-Downloads/releases).

No GitHub or GlideLink account is required to download a published public release. Download the installer from its release's **Assets** section and follow the release instructions. Testing previews are marked as prereleases.

## Setup

1. Connect your Android phone and Windows PC to the same local network.
2. Install the Windows companion and open **GlideLink Service Pairing**.
3. Pair from GlideLink on Android using the PC's QR code.

Only pair phones you trust: a paired phone can control sensitive PC screens. The upcoming 0.16 testing installer is experimental and unsigned, and requires administrator access to install its Windows service.
